# Architecture — Phase 2 contract/security boundary

`services/agent-gateway` contains the copied Codex bridge, Gemini/OpenRouter adapters, MCP Host, and internal HTTP runtime. `packages/contracts/agent.v1.json` owns generic runtime, event, egress, and sandbox-only approval envelopes. `agent_security.ts` enforces generic owner/turn/digest/expiry approval binding in the Codex bridge and defines context-egress consent checks for later consumers. These checks do not grant Janus domain operations.

Janus owns `janus-context.v1.json`, source authorization, PIT/as-of, provenance, sanitization, canonical facts, the approval deny policy, investment auth, Chat API/storage, User/Admin UI, and the currently deployed gateway. The Janus `assistant.v1.json` and `engine_security.py` remain live compatibility implementations; no service imports this repo's source at runtime. `JanusContextClient` is the isolated authenticated bounded HTTP consumer; it is not wired into live turn routing. It never reads Janus PostgreSQL, GCS, Iceberg, or internal packages. No Chat storage cutover or cross-project live integration is claimed.
